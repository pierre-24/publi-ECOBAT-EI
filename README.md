# Reaction at electrode interface (EI)

A publication about reaction at Calcium electrode interface, by Dr. [P. Beaujean](https://pierrebeaujean.net) and Prof. B. Champagne.

This repository contains the [curated data](./data), the [analysis scripts](./analyses), [the source for other images](./im), and the text.

**Latest PDFs:** [main text](https://github.com/pierre-24/publi-ECOBAT-EI/releases/download/latest/Main_Text.pdf), [supporting info](https://github.com/pierre-24/publi-ECOBAT-EI/releases/download/latest/Supporting_Info.pdf).
